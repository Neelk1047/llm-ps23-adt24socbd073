# PS 23 - Concept Explainer (ELI5)

**Student:** Neel Kalshetty | **Roll No:** adt24socbd073 | **Class:** LY Core 5

## Problem statement
Complex topics confuse beginners. This app explains any concept at three levels - Kid, Student and Expert - each shown in its own tab.

## Tech
Python, Streamlit, Google Gemini 2.5 Flash (`google-genai`), python-dotenv.

## How to run
```bash
git clone https://github.com/Neelk1047/llm-ps23-adt24socbd073.git
cd llm-ps23-adt24socbd073
pip install -r requirements.txt
cp .env.example .env      # Windows: copy .env.example .env  -> then paste your free key from aistudio.google.com
streamlit run app.py
```
